# Telecomunications Project

Triangulation of a sound echo utilizing microphones.
More detailed explanation found [here][documentation].

This repository contains the [source code] for the
ESP32-DEVKIT-V1 board, the algorithm used to
triangulate the microphones and the project's [documentation].
